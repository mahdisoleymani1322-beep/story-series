# story-series — Claude Skill

Turn any topic in any niche into a narrator-led educational story for Reels/TikTok — a multi-episode series (default 3) or a single story episode — with story world, season arc, scene-by-scene script, narrator voice-over, episode openers and cliffhangers, a scored critique loop, and hand-off blocks for video generation. Complements the `hook` skill. Persian by default.

## Install
Copy the `story-series/` folder into your Claude skills directory (or zip it and upload it as a skill in Claude settings).

## Structure
- `story-series/SKILL.md` — router
- `story-series/references/` — stage files (brief → output), story science, calibration example
- `story-series/scripts/verify.py` — output checker
